# Проект online store app

## Описание:
E-commerce — электронная торговля, или электронная коммерция. 
На данном этапе подготовим всё для того, чтобы у нас появилось ядро для интернет-магазина.
В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.

### Основные модули 

* Модуль в корне проекта *main.py* запустив который, можно получить результат всех реализованных 
в проекте функциональностей

В директории **src** создаются модули

* Модуль **category** 

1. Создан класс Category и определены необходимые атрибуты

* Модуль **product** 

1. Создан класс Product и определены необходимые атрибуты

* Модуль **utils** 

1. Функция *load_data_from_json* загружает данные из JSON и возвращает список 
объектов Category с вложенными Product

* Модуль **product_iterator** 

1. Создан класс *ProductIterator* - итератор для перебора продуктов в конкретной категории

* Модуль **smartphone** 

1. Создан класс наследник Smartphone класса Product

* Модуль **lawngrass** 

1. Создан класс наследник LawnGrass класса Product

* Модуль **base_category** 

1. Создан абстрактный класс BaseCategory для категорий товаров и заказов

* Модуль **base_product** 

1. Создан абстрактный BaseProduct базовый класс для всех продуктов

* Модуль **order** 

1. Создан класс для оформления заказа на один вид товара

* Модуль **exceptions** 

1. Создан класс исключение для товаров с нулевым количеством

## Установка

1. Клонируйте репозиторий:

`git clone git@github.com:SlavaMuzhev/online_store_app.git`

2. Перейдите в папку проекта:

`cd C:\Users\........\online_store_app>`

3. Установка зависимостей:

`pip install -r requirements.txt`

## Зависимости
* Python 3.x
* Библиотеки, которые указаны в requirements.txt

## Тестирование
Для тестирования используется библиотека **pytest**

Тестами покрываются все функции, находящиеся в модулях из пакета src

Установка pytest:

`poetry add --group dev pytest`

Запуск pytest удобнее всего производить из PyCharm. 
Для этого выполните следующие шаги:
1. Откройте окно Edit Configurations
2. Нажмите на "+" для создания новой конфигурации и выберите pytest
3. Укажите директорию с тестами и директорию проекта в целом

В pytest для анализа покрытия кода надо поставить библиотеку 
**pytest-cov**

Через poetry с добавлением в отдельную группу:

`poetry add --group dev pytest-cov`

Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:

`pytest --cov`  — при активированном виртуальном окружении.
